
Un panel a **3 états** gérés via le CSS.

---

## État normal
Le style de base du panel, tel qu'il apparaît une fois chargé.
```scss
monpanel {
    transform: scale( 1 );
    opacity: 1;
}
```

---

## :intro — apparition
L'état du panel **au moment de sa création**.
S&box transition automatiquement depuis cet état vers l'état normal.
```scss
&:intro {
    transform: scale( 0 );
    opacity: 0;
}
```

---

## :outro — suppression
L'état du panel **quand `Panel.Delete()` est appelé**.
S&box attend que la transition soit terminée avant de supprimer le panel.
```scss
&:outro {
    transform: scale( 0 );
    opacity: 0;
}
```

---

## Exemple complet
```scss
monpanel {
    transition: all 0.3s ease-out;

    transform: scale( 1 );
    opacity: 1;

    &:intro {
        transform: scale( 0 );
        opacity: 0;
    }

    &:outro {
        transform: scale( 0 );
        opacity: 0;
    }
}
```

> [!tip]
> Aucune ligne de C# nécessaire — tout est géré par le CSS.
