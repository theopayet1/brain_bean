
### display 
`display: flex` est la **valeur par défaut** sur tous les panels. Pas de `grid`, pas de `block` — tout est flex.

### position absolute
En CSS web classique, `position: absolute` est relatif au premier
ancêtre qui a `position: relative`.

En s&box, c'est plus simple : **toujours relatif au parent direct**, peu
importe ce que le parent a comme position.
```scss
.parent {
    width: 200px;
    height: 200px;
}

.enfant {
    position: absolute;
    top: 0px;
    left: 0px;
    // → coin haut-gauche du .parent, pas de l'écran
}
```

> [!tip]
> Pour couvrir tout l'écran, mettre `position: absolute` sur le panel
> racine qui est lui-même enfant direct du ScreenPanel.
