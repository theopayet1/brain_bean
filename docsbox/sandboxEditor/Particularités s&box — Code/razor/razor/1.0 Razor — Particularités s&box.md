## @inherits
Détermine le type de panel. Deux choix possibles :

`@inherits PanelComponent` — racine de l'UI, doit être sur un GameObject
avec un `ScreenPanel` (objet coller au joueur) ou `WorldPanel`(objet pas coller au joueur ) . C'est le point d'entrée.

`@inherits Panel` — panel enfant, utilisé à l'intérieur d'un `PanelComponent`.
C'est la valeur par défaut des fichiers `.razor`.

> [!warning]
> Un `PanelComponent` ne peut pas être utilisé comme enfant dans un autre
> panel avec `<MonComposant />` — uniquement les `Panel` le peuvent.

---

## `<root>`
Balise racine du fichier `.razor`. Tout le contenu du panel va dedans.
Son nom devient le sélecteur racine dans le `.razor.scss`.

```razor
<root>
    <div class="titre">Hello</div>
</root>
```

> [!tip]
> La balise peut s'appeler autrement que `<root>` mais son nom
> doit correspondre au sélecteur dans le `.scss`.

---

## @code
Bloc C# directement dans le `.razor`. Contient au minimum `BuildHash()`.

```razor
@code
{
    protected override int BuildHash() => System.HashCode.Combine( 0 );
}
```

> [!tip]
> Tant que la logique reste simple, tout mettre dans `@code` suffit.
> Le `.cs` séparé n'est utile que quand ça devient plus complexe.

---

## StateHasChanged()
Force le re-render du panel au prochain frame sans attendre que
`BuildHash()` retourne un nouveau nombre.

```razor
@code
{
    void MettreAJour()
    {
        // forcer le re-render manuellement
        StateHasChanged();
    }

    protected override int BuildHash() => System.HashCode.Combine( 0 );
}
```
